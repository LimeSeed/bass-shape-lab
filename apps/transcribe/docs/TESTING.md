## 已修复的问题

- 播放指针与 A/B 边界重叠时，边界触控命中被播放指针抢占：调整层级并保留独立指针入口，复测通过。
- 同步发生的存储写入异常：捕获并回滚事务，保留中文提示与元数据降级路径。
- 存储完全失败后自动保存误导性状态：记录当前歌曲是否真正持久化，保持“仅当前会话”提示。
- 已存歌曲切换后的内存引用：歌曲库只保留元数据；成功保存的历史歌曲不在会话缓存中重复保留Blob。当前歌曲与DSP仅保留所需内容。
- 原速原音使用透明PCM直通，避免不必要的DSP音高误差。

## 仍然存在的明确限制

- 50%速度/+12半音时输出约221.379 Hz，目标220 Hz，偏差10.82音分。官方原版对照也测得221.3805 Hz。原始严格阈值失败记录保留，未硬校正；不可作为精密调音工具。
- 极端速度/音高和短循环可能出现DSP音色与瞬态伪影，需要真人对实际音乐试听。
- 未验证真实 iPhone、Android、iPad、Safari/Firefox、蓝牙/外置声卡、锁屏后台播放、操作系统PWA实际安装流程及长期GC/物理内存回收；不能宣称零内存泄漏。
- 单声道/双声道、180 MB文件与256 MB解码PCM上限；完整解码过程仍可能在小内存设备上失败。未验证全部编码组合和超长歌曲。
- 未进行公网部署，也未验证中国大陆外网访问。
- AI 分轨仅有[独立验证路线](AI-SEPARATION.md)，尚无首版模型推理实验。

## 复现

需要 Node >=22.12、pnpm 和可运行的 Chromium 浏览器。默认浏览器路径是此 Mac 的 Microsoft Edge；其他环境通过 `BTL_BROWSER` 指定可执行文件路径。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm preview --port 4173
```

保持预览运行，在另一个终端执行：

```sh
pnpm test:browser
node tests/failure-ui.mjs
```

`test:browser` 依次执行新版段落、快捷键触控、存储、生产离线测试，默认127.0.0.1:4173；UI/Touch可用BTL_BASE_URL覆盖，生产测试可用BTL_URL覆盖。每组使用独立浏览器上下文。会重写其JSON/Markdown测试证据与截图。

音频DSP测试需要开发服务器（测试从本地源码加载引擎，便于直接测量PCM）：

```sh
pnpm dev --port 5178
pnpm test:dsp
node tests/dsp-compare.mjs
```

DSP_URL可覆盖音频测试地址。脚本明确分别报告严格1 Hz检查与20音分实用容差；完整保留最初失败记录。

子目录复现：

```sh
pnpm preview --port 4174 --base /bass/
node tests/subpath.mjs
```

测试样本均自产，见tests/fixtures/README.md。JSON原始记录位于tests/；界面截图位于docs/。
