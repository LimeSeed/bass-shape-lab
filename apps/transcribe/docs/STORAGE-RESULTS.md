# 本地存储浏览器回归结果

测试日期：2026-11-19。环境：macOS，Microsoft Edge 157.0.4341.60，无头浏览器，独立临时浏览器上下文。测试脚本：[tests/storage.mjs](../tests/storage.mjs)。

**结果：9 项通过，浏览器未捕获错误 0 条。**

| 用例 | 实际结果 |
| --- | --- |
| 保存与读取 Blob；歌曲列表不加载 Blob | 通过。原字节可读回，列表记录不含 `blob` 字段。 |
| 同一歌曲并发保存参数 | 通过。最后一组参数生效，音频 Blob 保留。速度 0.65、位置 4.25 秒、标记“主歌”均可读回。 |
| 页面刷新后恢复 | 通过。音频字节、速度、位置、音高、A/B、循环、间隔与标记可读回。 |
| 只更新元数据 | 通过。歌曲改名后，先前音频仍可读回。 |
| 模拟音频配额不足 | 通过。音频未保存，练习元数据成功保存；返回包含“存储不足”的明确降级提示。 |
| 模拟全部存储写入失败 | 通过。抛出包含“存储不足”的错误，没有返回保存成功。 |
| 自动保存时模拟配额不足 | 通过。返回包含“存储不足”的错误，原先位置 4.25 秒及其他参数保持完整。 |
| 删除与迟到自动保存竞态 | 通过。元数据和音频均被删除，迟到参数保存不重建歌曲。 |
| 申请持久存储 | 通过。返回布尔值；本次浏览器实际返回 `false`，没有伪称已获永久保存许可。 |

配额失败使用浏览器 IndexedDB `put` 故障注入，以确定性触发错误分支；没有填满用户磁盘。此测试覆盖真实 IndexedDB、Blob、事务、刷新和异常处理，模块由 Playwright 提供到独立 localhost 页面，不依赖正在开发的主页面。用于保存的 17 字节 Blob 是测试字节；实际音频解码与播放由 DSP 和主应用测试另行验证。

发现并修复：歌曲保存和参数自动保存的同步写入异常原本可能在 IndexedDB 请求回调内变成未捕获浏览器错误。现已捕获异常、终止事务并返回可处理的中文错误；相同故障注入下未捕获错误为零。

复现命令：

```sh
node tests/storage.mjs
```

默认使用 macOS Microsoft Edge。其他平台可设置环境变量 `BTL_BROWSER` 为已安装的 Chromium 系浏览器可执行文件路径。本测试只启动独立临时浏览器数据目录，不读取或更改常用浏览器的歌曲库。

未覆盖：实际磁盘耗尽、浏览器主动回收存储、浏览器关闭后重启、隐私模式各厂商差异、跨系统迁移与真实移动设备。
