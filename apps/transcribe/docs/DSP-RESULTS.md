# 真实 DSP 输出测量

2026-11-19，本机 Edge 157，Web Audio 输出 PCM 采集；未验证扬声器/耳机的物理输出。全部样本为自产合成音。

| 输入110 Hz/3秒 | 输出频率 Hz | 输出播放时长 s |
| --- | ---: | ---: |
| 原速/原音 | 110.000 | 3.013 |
| 50%/原音 | 110.621 | 6.008 |
| 原速/+12半音 | 220.667 | 3.001 |
| 50%/+12半音 | 221.379 | 6.008 |
| 原速/+24半音 | 440.716 | 3.001 |

速度与音高独立成立：50%速度保持基频并把时长翻倍，+12/+24分别使基频接近2倍/4倍而保持原时长。这不是播放率变更导致的同步变调。

**保留的限制**：最初严格±1 Hz检查在50%/+12组合失败；Signalsmith官方原版对照也测得221.3805 Hz（频谱峰221.38 Hz）。最大误差约10.82音分。另以明确的±20音分实用容差检查通过；没有篡改严格失败记录或按误差硬校正。它是练习和辨音工具，不能替代精密调音基准。

0.5–1.1秒源区间、0.5倍速度、0.2秒间隔，音频线程循环周期为1.4秒，连续周期误差低于1e-12秒（浮点数精度，非物理输出延迟）；实际静音段0.200045秒。用户界面位置由音频线程更新并插值；浏览器消息/屏幕刷新仍有显示延迟。

seek切换110/330 Hz片段后输出约110.000/330.000 Hz；暂停位置不继续漂移。48 kHz双声道独立验证；120次连续seek/调参/暂停恢复、12次buffer替换、强EQ测试未检测到NaN或处理异常，强EQ峰值约0.747。原始数据见 tests/dsp-results.json、dsp-stress-results.json 与 dsp-official-comparison.json。

seek与启停显式重置DSP并用6–8ms淡入淡出减小瞬态；节点断开、端口关闭、音频上下文关闭经过检查。没有测量真实设备长期GC/物理内存回收，不能声称已证明零泄漏。极端参数的音色与听觉质量尚需实际音乐和设备试听。
