# 验证与测试

## 重现自动检查

使用 Node.js 22.12+，在项目根目录运行：

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

浏览器测试使用生产构建，自动启动 `127.0.0.1:4173` 的预览。首次运行前需存在 `dist/`；`npm run dev` 不启用 Service Worker，不能代替生产版 PWA 验证。已有兼容浏览器时，可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定可执行文件，避免额外下载。

| 层次 | 检查内容 |
| --- | --- |
| 乐理 | 十二根音的自然大调音阶与自然小调音阶、七类和弦、正确字母与升降号、单个音程；保留调内和弦函数的独立测试 |

| 界面 | 默认 E 自然大调音阶、三个模式、全部根音与和弦组合、音程默认纯五度及切换、音名 / 音级、隐藏与揭晓、复制链接、安装说明 |

## 人工复核

1. 默认 E 自然大调音阶构成音为 E、F♯、G♯、A、B、C♯、D♯，指板始终显示 1–12 品；界面只有音阶、和弦、音程三种模式。
2. 在“音程”检查默认纯五度，E 根音对应 E 与 B；切换小三度、同度，检查目标音、音级及同度去重。复制单个音程设置的链接，在另一浏览器恢复。
3. 旧 E 大调Ⅱ级小七链接应恢复为与 F♯m7 等音的和弦 Shape（根音入口使用标准等音拼写），音级为 1、♭3、5、♭7；旧跟随范围应变为固定 1–12 品。
4. 隐藏答案后仅保留位置与根音颜色，构成音列表及指板标签均不泄露答案；揭晓恢复。
5. 实机竖屏滑动到指板最右端，横屏查看完整指板，再切回竖屏检查控件与文字可操作。
6. 在生产版首次联网打开，等待“离线已就绪”，关闭网络，刷新带不同设置参数的入口并继续切换模式。
7. 发布第二个构建，返回旧页面等待更新提示；确认之前旧页面继续可用，点击更新后当前设置保留；重新断网刷新确认新缓存完整。
8. Safari 与 Android 浏览器分别测试主屏幕安装；清除站点缓存后首次断网不应被误判为可用。

大陆网络的正式验收表见 [部署说明](DEPLOYMENT.md#中国大陆真实网络验收)。本机自动测试无法证明特定真实设备的安装行为或运营商网络可达性。
